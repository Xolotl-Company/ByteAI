# Byte Ai

Bienvenido a Byte AI 🚀 En este proyecto, construiremos una aplicación sencilla al estilo de ChatGPT utilizando Vite, React, TypeScript y Chakra UI v3 para una interfaz de usuario rápida, moderna y altamente personalizable.

## Tech Stack

- Vite: Para un desarrollo rápido y optimizado sin configuración.
- React: La biblioteca de interfaz de usuario para construir nuestra interfaz.
- TypeScript: Agregando tipado estático a JavaScript para mejorar la experiencia de desarrollo.
- Chakra UI v3: La última versión de Chakra UI.

## Getting Started

### Prerequisites

Antes de comenzar, asegúrate de tener Node.js (v20 o superior)
### Installation

- Clona este repositorio:

```bash
git clone https://github.com/xolotltech/byte-ai.git
```

- Ve al directorio

```bash
cd Byte-AI
```

- Instala las dependencias:

```bash
npm install
```

- Inicia el servidor de desarrollo:

```bash
npm run dev
```

Esto lanzará la aplicación en http://localhost:5173 (o según lo especificado en la terminal).
